# 01_frontend

프론트엔드 기초 학습 자료와 실습 예제를 모아둔 저장소입니다.

HTML, CSS, Git, JavaScript 입문 내용을 주차별 슬라이드와 실습 코드로 정리합니다.

## 구성

```text
.
├── slides/      # 강의 슬라이드 PDF
└── exercises/   # 실습 예제 코드
```

## 폴더 규칙

- `slides/{차시코드 앞 2자리}`: 해당 분류의 강의 자료
- `exercises/{차시코드 앞 2자리}/{차시코드}`: 해당 차시의 실습 코드

예시는 학습 흐름에 맞춰 번호순으로 확인하면 됩니다.
