2. 인라인 및 외장 스크립트 (<script>) 실습

HTML에 자바스크립트를 포함시키는 두 가지 핵심 방식의 작동 원리를 체득합시다.

방식 1) 인라인 스크립트 (Inline Script)

HTML 파일 내부 <body> 하단부 <script> 태그 내에 직접 자바스크립트 문장을 삽입하여 구동하는 환경입니다.

방식 2) 외장 파일 스크립트 (External Script)

프로젝트 규모가 커질 때 유지보수를 위해 자바스크립트 전용 파일(.js)을 따로 개설하고 링크하여 로딩하는 실무 표준 환경입니다.
