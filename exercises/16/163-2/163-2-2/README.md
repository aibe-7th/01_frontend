# 실습 2: 프로필 아바타 설정 및 스토리지 연동

프런트엔드에서 Supabase Storage(객체 스토리지)에 이미지를 직접 업로드하고, 획득한 Public URL을 데이터베이스 테이블에 연결하는 실습 프로젝트입니다.

## 1. 데이터베이스 및 스토리지 준비

### A. 프로필 테이블 생성
Supabase Dashboard -> SQL Editor로 이동하여 아래 쿼리를 실행하세요.

```sql
-- 1. 사용자 프로필(profiles) 테이블 생성
create table profiles (
  id bigint generated by default as identity primary key,
  nickname text not null,
  avatar_url text,
  updated_at timestamp with time zone default now() not null
);
```

## 2. 테이블 스키마 명세 (PK 및 타입)

### A. `profiles` 테이블 (사용자 프로필)
| 컬럼명 | 데이터 타입 | 제약 조건 | 설명 |
| :--- | :--- | :--- | :--- |
| **`id`** | `bigint` | **`PRIMARY KEY` (기본키, 자동 증가)** | 프로필 고유 식별 ID |
| `nickname` | `text` | `NOT NULL` | 사용자 닉네임 |
| `avatar_url` | `text` | | Storage에 저장된 프로필 이미지의 Public 접근 URL 주소 |
| `updated_at` | `timestamp with time zone` | `DEFAULT now()`, `NOT NULL` | 프로필 정보의 최종 등록/수정 시각 |

- **Storage 연계**: `avatar_url` 컬럼에는 실제 파일을 담지 않고, Supabase Storage `avatars` 버킷에 업로드 후 획득한 파일의 고유 Public URL 텍스트를 문자열 주소로 연결하여 활용합니다.

### 💡 핵심 키워드 및 기술 요소 해설

1. **`avatar_url text` (텍스트 기반 파일 경로 저장)**
   - **의미**: 프로필 사진 이미지의 바이너리 파일 자체를 데이터베이스의 일반 컬럼에 저장하지 않고, 문자열 주소(Public URL Link) 형식으로 기록하는 데이터 타입 설계입니다.
   - **기능/목적**: 관계형 데이터베이스(RDB)에 메가바이트 단위의 고용량 멀티미디어 바이너리를 직접 욱여넣으면 조회 성능이 극도로 저하되므로, 파일 데이터 자체는 전용 객체 스토리지(Storage)에 안전하게 격리하고 데이터베이스에는 주소 텍스트만 가볍게 연결하여 효율을 대폭 증대시키는 목적을 가집니다.

2. **`timestamp with time zone default now()`**
   - **의미**: 시간대(Timezone) 정보를 포함하는 시각 정보 필드와 기본값 자동 채우기 속성입니다.
   - **기능/목적**: 데이터를 추가/수정하는 시점의 국제 표준 시간을 데이터베이스 엔진이 직접 획득해 자동으로 채워 넣으며, 이를 활용하여 최신 아바타 등록자 순으로 갤러리 정렬 및 노출 처리를 수행하는 데 활용됩니다.

3. **`Public bucket` (객체 스토리지 공개 권한 설정)**
   - **의미**: 스토리지 버킷 내에 업로드된 객체(이미지 파일)를 별도의 로그인 인증이나 다운로드 중계 API를 거치지 않고 웹상의 모든 방문객에게 파일 다이렉트 주소만으로 조회를 허용하는 공개 설정 속성입니다.
   - **기능/목적**: 프런트엔드 애플리케이션의 HTML `<img>` 태그 `src` 속성에 업로드 후 취득한 Public URL 경로를 직배송하여, 추가적인 보안 토큰 연산 검증 없이 즉각적으로 빠르고 가볍게 브라우저 화면에 렌더링되게 가이드하기 위해 활용됩니다.

### B. Storage 버킷 설정
1. Supabase Dashboard -> Storage 메뉴로 이동합니다.
2. "New Bucket" 버튼을 클릭하고 버킷 명을 `avatars`로 입력합니다.
3. ⚠️ **중요**: **"Public bucket"** 옵션을 반드시 활성화(체크)해 주세요.  
   *(비활성화 시 업로드된 파일 주소로 브라우저에서 직접 이미지를 조회할 수 없습니다.)*

## 2. API 접속 정보 설정
- `script.js` 파일 최상단의 아래 변수들에 본인의 Supabase 프로젝트 정보를 입력합니다.
```javascript
const SUPABASE_URL = "본인의_SUPABASE_PROJECT_URL";
const SUPABASE_ANON_KEY = "본인의_SUPABASE_ANON_KEY";
```

## 3. 주요 실습 내용
- **Storage Upload**: 파일 바이너리를 Storage에 업로드하고 Public URL 획득
- **DB Link**: 획득한 아바타 주소와 입력받은 닉네임을 데이터베이스 `profiles` 테이블에 저장
- **Gallery Read**: 등록된 프로필 리스트를 동적으로 화면에 조회하여 렌더링
